# 0.0.44：扩展的 MCP 编辑功能

## 怎样连接

保存工程并退出旧编辑器，启动程序目录的“启动编辑器.bat”。打开工程后进入“剧情助手”，点击“开启本地 Agent 接口”，再点击“复制 MCP 配置”。把新配置交给你使用的 Agent。

旧配置指向旧程序或旧窗口，不会自动获得新接口。每个已开启接口的编辑器窗口有自己的连接；关闭窗口后该连接失效。

## 这次补齐了什么

旧接口 23 个，这次扩展到 37 个。原来的读故事、编排粗稿、布置环境、撤销、保存、试玩和导出保留。

## Agent 的常用顺序

1. 用 get_project 获取当前版本号和素材 ID。
2. 用 get_capabilities 查看允许的对象、字段与操作。需要滤镜时，用 get_render_options；需要骨骼或表情时，用 inspect_character。
3. 用 get_objects/get_object 读取要编辑的对象。不要猜 ID。
4. 用 edit_project 分批修改。每批最多 200 项；同一批失败时，不会留下半份修改；成功后可以整批撤销。
5. 用 select_editor_object 或 open_editor_panel 选择要检查的画面，再用 capture_editor 查看。
6. 保存独立窗口的修改时使用 sync_editor_windows；环境窗口使用原来的 sync_environment_editor。保存后重新读取版本号。
7. 最后 save；需要时 preview 或 export_game。

所有修改都要带最近读取的 expectedRevision。版本变了就重读，不覆盖作者的新修改。

## 新工具名称

- get_capabilities：功能和字段清单。
- get_editor_state：界面、窗口、预设和当前选择。
- get_objects/get_object：对象列表与详细内容。
- get_render_options：全部滤镜范围及说明。
- edit_project：直接批量编辑工程。
- inspect_character：实际人物模型检查。
- generate_portrait：生成角色头像。
- import_dialogue_voice：对白配音导入。
- find_text：查找可见文字；替换用 edit_project 的 replace_text。
- open_editor_panel/select_editor_object：打开或选择要检查的内容。
- capture_editor：截图；panel 可选 main、characters、items、title、render、knowledge。
- sync_editor_windows：保存角色、物品、标题、渲染和知识库窗口中的待应用修改。

## 一批修改的例子

先读取版本号和真实素材 ID，再调用 edit_project：

```json
{
  "expectedRevision": 123,
  "operations": [
    {"action":"create","kind":"act","ref":"chapter","data":{"name":"见面"}},
    {"action":"create","kind":"dialogue","ownerId":"$chapter","ref":"line","data":{"text":"你好！","characterId":"真实角色ID"}},
    {"action":"set_actor","id":"$line","slot":"center","data":{"characterId":"真实角色ID","offsetX":0,"offsetY":0,"offsetZ":0,"yaw":0,"size":1.15}}
  ]
}
```

ref 是这批操作里的临时名字，后面可以用 $chapter、$line 引用刚创建的对象；返回结果会给出真实 ID。

## 仍需在界面中进行的内容

工程的新建、打开和另存为仍在界面中进行，MCP 操作已连接的当前工程。鼠标拖动、快捷键和播放音频的临时进度等，不逐个模拟按键；对应的制作结果通过数据接口设置。

模型和动作本身的二进制内容、模型原始贴图制作与骨骼改造，不由此接口修改。真实玩家的存档、解锁进度、工程保护设置不开放。已经取消的 Android 导出不恢复。

角色专属和通用动作文件夹、配音文件夹不可删除。仍被使用的素材不能直接删除；先调整引用。外部原始素材始终保留。
