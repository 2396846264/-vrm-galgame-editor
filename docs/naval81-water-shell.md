# 0.0.81 水中弹

100 毫米及以上舰炮默认启用水中弹，无需调整参数。小口径武器、炸弹及鱼雷保持各自原有处理。

- 炮弹接触海平面时产生青白色水柱与扩散水环，随后进入水下弹道，不再在海面直接消失。
- 入水瞬间保留 45% 速度和 70% 剩余伤害预算，之后持续受水阻减速。这是游戏用的简化参数。
- 穿甲弹可命中、贯穿水线以下的船体，继续按方块当前生命扣减剩余预算；不附带范围爆炸。
- 高爆弹入水约 0.04 秒后爆炸；若先撞到船体则在撞击点爆炸，保留原有爆炸半径，水下伤害为入水后的预算。
- 水下航行最多 1.2 秒、深度最多 18 米，航程为口径毫米数乘以 0.3 米（限制在 30–140 米），且仍受舰炮总射程约束。达到边界后结束，不会无限游走。
- 水阻采用连续减速，没有模拟跳弹、复杂流体或进水浮力；本次不改变战舰吃水设置。

验证入口：`node scripts/test-naval-water.mjs`，以及既有 `test-naval80.mjs`、`test-naval70.mjs`、`test-aircombat.mjs`。原生 `--smoke-naval80` 进一步覆盖实际水下穿甲命中、入水高爆延迟、海战声音、保存重开与游戏导出。
