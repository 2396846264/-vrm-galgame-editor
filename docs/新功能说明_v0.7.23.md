# v0.7.23：给每一幕加天气

## 一分钟开始

1. 打开新版软件，打开你的工程。
2. 点击左边的“剧情”，选择要修改的一幕。
3. 在右边找到“本幕天气”，它在“背景音乐”下面。
4. 选择“下雨”“下雪”“刮风”“阳光明媚”或“阴天”。
5. 中间的预览会马上变化。调整好后，点击“保存”。
6. 点击“试玩”就能看到带声音的天气。要给别人玩，请重新导出游戏。

![每幕天气设置](docs/images/weather-editor-v0723.png)

旧工程默认选择“无天气”。第一幕下雨，不会让第二幕也下雨；标题和人物鉴赏没有天气。

## 这些按钮怎么用

| 设置 | 简单说明 |
|---|---|
| 天气强度 | 越大，雨雪或飘落物越多；0% 就不显示天气 |
| 风速、风向 | 控制向哪边吹、吹得多快；风会有缓慢的阵风变化 |
| 风吹动模型的头发与衣物 | 模型带有可摆动的头发或衣物时，加入轻微风力；不适合的模型可以关闭 |
| 显示地面水花与细小涟漪 | 雨天可开启；室内或水花位置不合适时可以关闭 |
| 地面起点 | 水花从画面的哪一条水平线开始；左移往上，右移往下 |
| 阳光位置 | 把光源放在画面左边或右边，最好对准背景原本的太阳方向 |
| 柔和光束 / 空气薄雾 | 晴天显示柔光，雨雪和阴天显示少量薄雾 |
| 天气自动配色与人物配光 | 根据天气轻微改变人物与背景的气氛；仍然保留你对本幕的手动调色 |
| 天气声音 | 内置雨声 / 风声，或者选择自己导入的音频；也可以静音 |
| 天气音量 | 只调整这一幕的天气声；玩家的“按钮与场景音效”音量会同时控制它 |

编辑器预览不播放天气声。试玩时会播放；看完这一幕或返回标题后会切换或停止。

## 雨：细雨到大雨

雨丝有不同距离、速度、长度和透明度。远处雨丝会被人物遮住，近处雨丝会经过人物前面。风会改变雨丝的方向。

地面水花和涟漪从你选定的“地面起点”开始。请对准背景的路面，避免水花出现在墙壁上。普通背景图片没有可自动识别的真实地面，所以这个位置由你来调。

![雨天实际画面](docs/images/weather-rain-v0723.png)

## 雪：有远近的飘雪

雪花大小、速度、形状和透明度不同，有轻微左右飘动。近处雪花更明显，远处更细小。选择雪景背景会更自然；这个效果不会把原本的绿色地面自动画成积雪。

![雪天实际画面](docs/images/weather-snow-v0723.png)

## 风：落叶、阵风和模型摆动

落叶会随风移动、旋转和翻面。可以使用内置风声或自己录制的环境声。模型有可摆动的头发与衣物时，会加入轻微阵风；关闭天气后恢复原本的模型参数。

背景图片中的树木不会自动变成动画。需要树木明显摇动时，可以使用动态背景视频。

![刮风实际画面](docs/images/weather-wind-v0723.png)

## 晴天与阴天

晴天使用柔和光束、空气中的小光点和偏暖的人物配光；可以调整阳光从左侧还是右侧出现。阴天会柔和地降低亮度和饱和度，带少量空气薄雾。

![晴天实际画面](docs/images/weather-sunny-v0723.png)

## 推荐从这些数值开始

| 天气 | 强度 | 风速 |
|---|---:|---:|
| 细雨 | 30% | 15% |
| 正常下雨 | 55% | 25% |
| 大雨 | 90% | 55% |
| 轻雪 | 35% | 15% |
| 大雪 | 80% | 40% |
| 刮风 | 65% | 65% |
| 晴天 | 40% | 10% |

## 直接体验

新版文件夹中有“每幕天气示例.vrmg”。点击“打开”，选择它，然后点击“试玩”。五幕分别演示雨、雪、风、晴天和阴天。

示例是新建的独立文件，你原来的工程和素材没有被修改。

本版保留查找替换、PDF 知识库、每幕调色、自动头像和玻璃界面。天气粒子会一起进入油画效果，文字和操作按钮保持清楚。
