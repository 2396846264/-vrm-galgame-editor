# 海上空战与编辑器 0.0.51

运行 `Editor/VRMGalgame.exe`。本地安装目录为 `本地交付目录`，源码继续保存在原来的迁移包目录。

## 建造视角

在载具编辑器中打开一个载具文件，点击“进入第一人称建造”。W/S现在沿相机完整朝向前进或后退：抬头时W向斜上方移动，低头时向斜下方移动。A/D侧移；Space/Ctrl沿世界竖直方向上升/下降；Shift加速。组合移动会归一化，斜着移动不会额外加速。方块吸附、半边对称、附件和单文件保存保持原有功能。

## 新飞控

| 输入 | 行为 |
| --- | --- |
| W | 增加油门，松开后保持当前油门 |
| S | 减小油门并制动：飞行中增加空气阻力，平台上使用轮刹 |
| A / D | 左倾 / 右倾并产生倾斜转弯，松开后回正 |
| 鼠标向左 / 右偏离中心 | 直接操纵转向，偏离越多转向输入越大 |
| 鼠标向上 / 下偏离中心 | 直接操纵抬头 / 压低机头 |
| 鼠标回中或移出飞行画面 | 停止鼠标转向输入 |
| 左键 / Space | 发射机炮、机枪；实际弹道沿炮口方向 |
| B / F / G | 投弹 / 襟翼 / 起落架 |
| Esc | 暂停 |

加入侧倾回正、俯仰限制和迎角保护。机翼升力、投影面积风阻、发动机马力、受损组件和弹药依然参与模拟。低速仍会失速，S不能无限减速而保持悬空；及时使用W恢复速度。

玩家鼠标输入现在直接生成操纵量，没有保存鼠标指定的世界航向，也没有计算让飞机自动对齐鼠标目标方向的目标姿态。松开A/D的回正和俯仰配平仅参考飞机本身状态。AI导航仍独立工作。

## 海面和平台起飞

空战的陆地、网格和山丘已替换成广阔海面，包含波纹、高光、远处雾化与地平线。海面随相机平移，纹理相位保持连续。轮子不能在海水上滑跑或降落。

载具编辑器中的“平台起飞”提供海上训练平台，保留滑跑和起飞验证路径。自动起落架在确认离地后保持收起，避免爬升减速时反复放轮；G仍可以手动控制。这个平台用于训练，尚未模拟移动航母、阻拦索和弹射器。

## 场景中的水面 / 流水

主界面点击“编辑器 ▦”→“场景编辑器”，右侧点击“水面 / 流水”，可添加三种预制组件：

- 平静水面：池塘、湖面。
- 流水 / 河道：长条水面，带可调流向和流速。
- 瀑布 / 水帘：竖直水面，沿表面向下流动。

选中后可调整颜色、宽度、长度、波浪高度、波纹尺度、流速、流向、不透明度，以及普通物体的位置、旋转、缩放、可见性和分组。流向0度沿组件X轴，90度沿组件Z轴。水面组件随环境保存、重开和导出，MCP环境操作也支持`water`节点和这些参数。

调研参考了 [Three.js Water2](https://github.com/mrdoob/three.js/blob/r180/examples/jsm/objects/Water2.js)，该方案支持反射、折射和流动。本版本采用独立的轻量程序化水面着色器，没有额外水纹贴图下载，也没有为每块水面重复渲染反射/折射画面。高光和天空色反射是近似表现，不会映出场景中具体物体；水流是视觉组件，不模拟流体推动角色。

## 编辑器外观

依据用户指定的 [Apple Design Skill](https://github.com/dayviwong/apple-design-skill) 及其 [SKILL.md](https://github.com/dayviwong/apple-design-skill/blob/main/SKILL.md) 设计指引，采用黑白灰底色、蓝色强调、统一间距和圆角，集中编辑器入口为带图标和用途说明的选择页。主编辑器、场景和载具编辑器的工具栏与属性区统一配色。默认跟随系统明暗，也可在编辑器设置中选择固定日间或夜间。

界面优先适配Windows桌面和较小窗口，保留键盘焦点和减少动画偏好。图标为自绘SVG，字体使用系统/已有字体，没有打包Apple专有字体或SF Symbols。

## 专利调研边界

查阅了 Gaijin 的 [US8770979B2](https://patents.google.com/patent/US8770979B2/en) 和后续 [US9011152B2](https://patents.google.com/patent/US9011152B2/en)。其权利要求涉及输入期望飞行方向、分析需要的飞机及控制面调整、使飞机与该方向对齐的系统或方法。后者还关联 [US9858830B2](https://patents.google.com/patent/US9858830B2/en)，所以不能只看一份早期专利或只改键位。

本次采用直接操纵输入并去除玩家目标航向对齐路径，是工程上的规避设计判断；这不构成完整专利自由实施评估，也不能保证没有法律纠纷。商业发行前仍应按发行地区、现行权利状态和相关专利家族评估具体实现。
