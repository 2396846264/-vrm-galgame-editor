# v0.7.28：反馈交流群与加密工程

## 顶部反馈交流群

编辑器顶部操作栏右侧新增 **Bug反馈交流群 · QQ 565407768**，可以在这里找到反馈交流的群号。

群号由原生程序提供，网页文件里不直接保存群号。程序启动时会检查界面文件的签名和内容；界面文件缺失或被修改时，会提示校验失败，要求重新解压完整安装包。

这能提高篡改界面和群号的难度，但不能保证软件绝对无法被破解。

## 工程包自动加密

- 新建工程时，工程包自动加密。
- 原来没有密码的 `.vrmg` 或 `.zip` 工程仍然可以打开。
- 用本版点击保存、自动保存、另存为，或把旧工程文件夹导入为工程包时，新写出的包都会加密。
- 正常使用软件打开和保存工程，不需要输入密码。
- 工程清单和包内素材一起加密，使用 AES-256。
- 密码不显示在界面，不写入使用说明、更新日志或工程清单。

**加密后的工程需使用 v0.7.28 及后续支持此格式的版本打开，v0.7.27 和更早版本无法读取。** 原来的未加密工程在保存之前仍保留原格式。

保存原有工程时，软件继续采用临时写入再替换的方式，上一次保存的备份仍保留在本机备份目录。

## 试玩与导出

试玩和导出游戏照常使用。工程包密码保护的是工程压缩包；导出的游戏继续使用游戏运行所需的文件结构，玩家不需要工程密码。

导出的游戏和临时试玩程序也带有界面文件校验。不要自行替换 `web` 里的文件，否则校验会失败。图片、模型、配音等内容应当在编辑器的工程中修改。

## 启动新版

打开“新版_v0.7.28_反馈群与加密工程”，双击 `VRMGalgame.exe`。完整解压后使用；程序、`web`、`web.integrity.json`、`WebView2Loader.dll` 和 `preset-motions` 必须放在一起。
