# 0.0.88 海战样板、地图与编队

火力编辑器的斜面按摄像头方向吸附，R 键或右上角按钮追加 90° 旋转；选择已有方块后按 R 可旋转它。朝向随工程和炮塔文件保存。炮管改为轻微锥度、开口内壁和内凹暗膛，保留后坐和炮口焰。

战舰编辑器的打开列表和新建窗口提供大和、南达科他 BB-57 样板。舰体、装甲、分层舰桥、观察平台、色带与标记可逐块修改；三座三联主炮具备旋转和俯仰，桅杆、雷达、烟囱、副炮和旗杆为附件。这是参考历史主要尺寸和照片制作的原创低面数近似，并非逐年舰装考证复原。战斗仍使用游戏既定的口径射程与伤害规则。

战舰装饰分类可安装旗杆，选中后选择或上传旗面图片，布面自动飘动。飞机不能安装旗杆。旗帜随工程、游戏及独立战舰文件保存。

海空战幕提供开阔大洋、碧海单岛、远岸双岛、疏岛海域、外海礁群。主战区 70×70 km，每图最多六座低面数岛屿；种子固定，重开不改变地形。中央航道及默认出生区留空。飞机使用岛屿高度碰撞，舰队遇岛阻挡并转向；越过主战区边缘会转回，后方航母的补给走廊保留。

舰队以照片槽位显示阵型，点空位添加，点照片替换或清空；航母开关可选择航空母舰。友机可添加多个编队，每队最多七架，总计十五架，各队分别设置 150–6000 米高度和人字、横队、纵队。旧工程未配置编队时继续使用旧友机设置。

飞机、战舰和炮塔保存时自动生成 256×160 中轴线视角照片，存入文档元数据，不进入素材库。槽位使用保存后的照片；尚未保存的旧文件显示图标。

独立分享格式：飞机 .vrmair、战舰 .vrmship、炮塔 .vrmfirepower。炮塔可上传、选择和试听炮声，声音随炮塔文件分享，安装后优先使用该炮声。载具分享文件也携带自制炮塔的炮声。导入产生新文档与素材 ID，避免覆盖原素材。
