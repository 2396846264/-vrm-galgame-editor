# 公开版 0.0.7 查找替换与知识库

本版已补修标题书本入口：图标显示正常，按钮可以点击。更新后请关闭原先的编辑器和试玩窗口，再打开软件；以前导出的游戏需要重新导出。

## 1. 游戏名字在哪里改

点击编辑器左上方的“标题”，在右侧“游戏名称”中改名字。

顶部输入框现在用来查找文字。输入旧名字或一句话，按回车，或者点击旁边的放大镜。

## 2. 一次修改很多名字

1. 在“查找”框里输入旧名字，例如“绯音”。
2. 先看下方列出的内容，确认找对了。
3. 在“替换为”框里输入新名字。
4. 点击“全部替换”。
5. 如果改错了，点击“撤销上次替换”。

工具会查找：对白、剧情选项、幕名称、角色名字、角色介绍、角色故事和制作说明。它不会改模型文件、素材文件路径、动画和角色编号。

“替换为”留空表示删除查到的文字。查找按原文字精确匹配，不用写特殊符号。

![查找和替换示例](images/text-search-v0722.png)

## 3. 往知识库里放书

1. 点击“渲染”右边的“知识库”。
2. 点击“导入 PDF”，选择你的文档，可以一次选多本。
3. 选中一本书，在右边写书名和简介。
4. 选择“完成哪一幕后解锁”。
5. 封面默认用 PDF 第一页，也可以选择或上传另一张图片。
6. 点击“预览翻书”，在编辑器里查看效果。
7. 保存工程，再导出游戏。

![知识库编辑页](images/library-editor-v0722.png)

## 4. 玩家怎么看书

标题界面左上角有一个书本图标，点它进入书库。

未解锁的书显示黑白封面和红色“未解锁”封条。看完指定幕的全部对白后，才可以点开。没有设置解锁幕、或者指定幕已被删除的书，会保持锁定。

![书库与未解锁封条](images/library-shelf-v0722.png)

## 5. 像翻书一样阅读

书本以左右两页展开，有纸张底色、书脊、纸张厚度、阴影和立体翻页动画。

- 点击下方“上一页”“下一页”，或按键盘左右方向键。
- 原始大小时，按住书页向左或向右拖一段距离，也能翻页。
- 点击右上角“＋”“−”放大或缩小。放大后可以滚动查看。
- 关闭书本后再打开，会回到上次看到的页码。
- 最后一页如果落单，另一边会留白。

![双页阅读实际效果](images/library-reader-v0722.png)

这是纸张风格的立体翻页动画。PDF 原始内容保持原样，书页上不会重新排版。

## 6. PDF 怎么准备

- 使用正常的 `.pdf` 文件；建议去掉打开密码。
- 竖向 A4 或类似尺寸最适合双页阅读。横向文件也能打开，放大后查看更方便。
- 导出 PDF 时尽量嵌入字体，避免换电脑后缺字。
- 扫描文件的字要清楚；每页图片建议不要大到几十 MB，否则翻页会变慢。
- 自定义封面可用 PNG、JPG 或 WebP，建议竖图，比例约 2:3。
- PDF 会复制进工程包，随导出的游戏一起带走。离线也可以看，不需要玩家再安装 PDF 阅读器。

## 7. 试一试示例

公开版不附带完整素材示例工程。请新建工程并导入自己的 PDF，设置完成哪一幕后解锁；在编辑器中点击“预览翻书”即可体验。文中图片只是示例与效果图。

以前导出的游戏，请用新版重新导出到新的文件夹。不要只复制 EXE，要保留旁边的 DLL、`web` 和其他文件夹。
