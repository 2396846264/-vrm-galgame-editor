# 自动眨眼 · 0.0.49

VRM 与 MMD 人物强制启用自动眨眼，没有关闭选项。打开原有工程即可生效，无需重新导入模型或修改对白。

- 每个人物独立计时，随机间隔 6～12 秒，不会全体同时眨眼。
- 每次约 0.22 秒：快速闭合，短暂保持，然后稍慢地睁开；没有连续双眨。
- 对白中的人物、可动头像、标题人物和角色详情共用角色渲染机制。
- 手动闭眼、单眼眨眼、MMD 闭眼笑容和原生 VMD 眼睑动画优先。闭眼期间不叠加自动形态，恢复后重新等待完整间隔。
- 说话口型独立运行；暂停游戏时眨眼时钟也暂停。
- VRM 使用模型自带的 blink，缺少双眼通道时可组合 blinkLeft 与 blinkRight；遵守模型的 overrideBlink 规则。
- MMD 自动识别“まばたき”“瞬き”、英文 blink 和常见中文名称，支持左右眼组合。
- 需要模型自身有眼睑形态键。没有眼睑形态键的模型保持原样，不能靠移动眼球生成真正的闭眼。

直接运行 Editor/VRMGalgame.exe，打开已有 .vrmg 工程。载具编辑器及 0.0.48 的其他功能继续保留。

本次检查使用现有两个 VRM 人物、三个 MMD 人物，验证实际眼睑权重、实时渲染、可动头像、手动闭眼、VMD、工程保存与重开，以及导出游戏中的自动眨眼。检查报告位于程序包的 Verification 目录。
