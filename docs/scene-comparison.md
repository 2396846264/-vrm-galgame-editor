# 二次元场景试建与对照

这些场景通过本版本真实的本地 MCP 接口搭建，使用编辑器内生成的彩色立体几何体和程序水面，没有导入模型、原画或贴图。参考图用于观察布局、比例和配色，示例不声称复刻手绘背景。

## 1. 绿丘港口与拖船

参考：[《虞美人盛开的山坡》官方静止画页面](https://www.ghibli.jp/works/kokurikozaka/)，选用[第008张：港口拖船](https://www.ghibli.jp/gallery/kokurikozaka008.jpg)。

![港口实际试建](<images/agent-harbor.png>)

| 对照项 | 原图 | 实际场景与结论 |
| --- | --- | --- |
| 层次 | 水面与拖船在前，码头与建筑在中，绿丘在后 | 三层都已搭出，能直接看出港口主题 |
| 船的配色 | 深色船体、绿色船舷、浅色驾驶室、红白烟囱 | 对应配色已实现，轮胎护舷用圆环搭建 |
| 建筑 | 密集的港口仓库、招牌、瓦顶 | 暖色房屋、窗门和屋顶已实现；仓库细节、文字招牌和瓦片尚未表现 |
| 水岸连接 | 连续的岸边，没有空隙 | 第一轮发现块体陆地与水面之间漏了一条区域；第二次通过MCP扩大水面并调整镜头 |
| 画面角度 | 拖船正面占据画面中心 | 示例使用斜向镜头展示整套场景，构图并非逐像素匹配 |
| 风格差距 | 手绘笔触、密集植被、生活物件丰富 | 当前是简洁的几何体表达；草地网格和圆团状山丘仍明显 |

场景共 **15,115个几何体、188,796个三角面、9组实例渲染**。每块独立保存形状、位置、尺寸、朝向和颜色。

## 2. 花园住宅与石板路

参考：[《借东西的小人阿莉埃蒂》官方静止画页面](https://www.ghibli.jp/works/karigurashi/)，选用[第002张：庭院住宅](https://www.ghibli.jp/gallery/karigurashi002.jpg)。

![庭院实际试建](<images/agent-garden.png>)

| 对照项 | 原图 | 实际场景与结论 |
| --- | --- | --- |
| 主色 | 暖黄色墙面、灰绿屋顶、大量绿色植物 | 主色关系已实现，窗框和木质立柱可辨认 |
| 建筑 | 斜屋顶、门廊、竖向窗框和拱窗装饰 | 用楔形体、方块和拱形体组合，无模型素材 |
| 植被与道路 | 草地、藤蔓、花草和不规则石板路 | 层叠树冠、灌木、彩色花球、藤叶和石板已搭建；植物细节仍简化 |
| 遮挡 | 住宅与道路是可读的主体 | 第一轮树冠挡住了房屋和池塘；第二次通过MCP将树移到后方和两侧 |
| 自由扩展 | 原参考画面没有这组池塘和桥 | 示例加了池塘、木桥和石灯笼，用来验证水面与不同几何形状的组合 |
| 风格差距 | 丰富的叶片层次、墙面与瓦片纹理、手绘光影 | 当前保留结构和配色，尚不具备原图的纹理和细节密度 |

场景共 **6,787个几何体、132,128个三角面、9组实例渲染**。

## 实际验证

- 源码51项回归检查通过，包含飞控、水面、角色眨眼与视线等既有功能。
- 载具零件卡片在1050×650、1500×900、2560×1529三个尺寸下完整排版；幕列表四按钮在1024、1500、2560宽度下保持单行。
- 真实Agent桥接完成新建环境、打开编辑器、批量搭建、分页读取、单块改色、撤销重做、场景绑定、保存和导出。
- 未打开场景编辑器时的几何体创建被拒绝；普通用户界面没有几何体创建或单块编辑入口。操作完成后控制权交还用户。
- 两万个块体使用9个实例绘制对象，独立颜色与矩阵、释放资源及保存数据往返通过检查。超数量、超三角面、无效参数、过期版本和错误块体ID均有校验。
- 第二轮通过MCP替换几何体组、调整相机和水面，并使用 `capture_environment` 取得实际编辑器PNG，再输出不带编辑辅助线的1600×900场景图。
- 最终工程重新打开，两个场景的几何体保留；第一幕继续使用港口。重新导出游戏成功。

工程：`Agent二次元场景示例_0.0.52.vrmg`。进入场景编辑器“打开一个环境”，分别选择“Agent几何体港口”和“Agent花园住宅”。

这次试建确认了“不导入素材也能直接构建可复用场景”的完整流程。视觉上已能表达主题与空间层次；如果目标是手绘动画背景的精细程度，还需要更密集的造型、材质纹理和相应的美术渲染。
