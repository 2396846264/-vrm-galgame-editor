# OceanThreejs 水面与局部水体

海空战默认使用 OceanThreejs 海洋：FFT 风浪、长涌浪、天空反光、浪尖泡沫和深水颜色。无需联网下载贴图，也不需要额外安装插件。保留海空战幕原有的渲染预设、滤镜和颜色校准。

场景编辑器的“水面 / 流水”新增四种预设，沿用编辑器原有控件与外观：

| 水体 | 使用方式 |
| --- | --- |
| 海洋 · OceanThreejs | 大范围海面，可调整宽、长、水色、浪高、波纹尺度、风速和风向。海战自动使用跟随视点的大海。 |
| 池塘 | 椭圆形轻量水面，默认小幅波动。调整宽、长即可匹配池岸。 |
| 井水 | 小型圆形水面，默认非常平静；移到井口内部需要的高度。 |
| 喷泉水面与水柱 | 自带循环喷水粒子，可调整喷水高度。默认使用圆形水面。 |

原有平静水面、河道与瀑布继续可用，旧场景不会自动变成大海。井壁、池岸、喷泉底座由场景模型搭建；这些预设提供水体效果，不会自动建造建筑或进行溢流模拟。保存、重开、试玩和导出使用相同水体数据。Agent 场景接口支持 waterType、waterShape 和 jetHeight。

## 海战联动

- 舰船尾迹使用柔边泡沫，包含两侧扩散和中央螺旋桨水流；鱼雷留下更细的水中航迹。尾迹会跟随海面高度和倾斜方向，逐渐扩散、淡出。
- 舰体根据船身范围采样波浪，缓慢升沉、俯仰与侧倾；不改变航线、编队规则或武器射程。
- 鱼雷维持在局部水面下约 1.5 米，炮弹按当前波面判定入水，水花在实际入水点生成。
- 航母队列继续随甲板移动；降落判定使用倾斜后的甲板平面。

## 性能与适用边界

海洋默认使用 128×128 FFT，计算频率最高 30 次/秒；近处网格较密、远处网格较疏。小型局部水体不运行 FFT。尾迹最多 2048 片，喷泉每个 240 个水滴。

需要 WebGL2；无法使用浮点渲染目标时自动回退到长涌浪，仍保留水色与天空反光。FFT 的高度图通过异步缓存供玩法使用，约每 0.1 秒刷新；船体运动做平滑处理，因此属于适合游戏的近似浮动，不是流体浮力求解。不能保证所有显卡与场景达到相同帧率。

当前反光来自程序天空和太阳，并非对舰船、岸边建筑的完整镜面反射。局部水体沿用轻量水纹方案；井、池塘和喷泉不承担海战规模的波浪模拟。本版也未实现潜水镜头的整套水下后处理。
