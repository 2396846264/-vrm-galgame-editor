# 火力编辑器

在主界面的“编辑器 → 火力”打开独立窗口；飞机、战舰编辑器顶部也有入口。外观沿用编辑器现有主题与控件。

## 炮塔和炮管

红色核心方块固定在原点，不能删除或移动，是炮塔整体的水平旋转中心。红色线框帮助在外壳遮挡时定位核心。炮塔用方块搭建，支持正方块、斜面块、棱锥及颜色设置；保存时要求所有块连接到核心。可选透明球形外罩，用于轰炸机上的球形机枪塔。

中键拖动旋转视图，右键拖动平移，滚轮缩放。选择“添加方块”后左键点击已有块的表面添加；选择“选择方块”或“拆除方块”后左键操作对应方块。每次选择建造工具会把试转姿态归零。

高低机控制炮管俯仰，可分别输入其 X/Y/Z 位置。每个炮塔可安装 1～8 根炮管，各管相对高低机的位置可分别调整。炮塔外壳随水平轴转动，炮管随高低机俯仰。

炮管长度＝口径（毫米）×倍径÷1000，单位米。例如 127 毫米、50 倍径对应 6.35 米。正前方沿 −Z，右边为 +X，上方为 +Y。

## 射界、弹药与试射

水平起始角 −60°、终止角 60° 对应 120° 射界；−180°～180° 为全周。最低俯角、最高仰角独立设置。下方滑动条实时试转，实际战斗也执行这些角度限制，目标在射界外时不发射。舰装大口径炮的转速继续受统一游戏平衡上限约束。

可选择普通机枪弹、AP 穿甲弹、HE 高爆弹或三式弹；高平两用设置用于适用炮弹的对空近炸。舰装 100 毫米及以上炮继续使用现有的曲射、射程、高爆和穿甲伤害规则，小口径不套用重炮规则。

射速按每根炮管的每分钟发数设置，多根炮管在一轮中同时开火。弹夹由全部炮管共用，容量按实际炮弹数扣除；不足一轮时只发射剩余弹数。弹夹耗尽后按换弹时间等待。无弹夹时按射速持续装填，备弹仍会消耗。“试射 / 停止”可预览后坐、炮口闪光、余弹和换弹倒计时。

## 保存和安装

点击“保存到工程”，组件保存在当前工程内。进入飞机或战舰编辑器，在“自制火力组件”中选用，再进入第一人称建造，瞄准机体或甲板左键安装。中键选中已装组件，可调整挂载位置、方向与倍率。

安装时保存一份组件快照，因此修改库中的炮塔不会悄悄改变已有载具。需要更新时，选中载具上的组件，点击“更新为库中当前版本”，再保存载具。所有引用该载具的海空战幕随载具保存同步；工程归档、重开和游戏导出均携带火力数据。

当前自制炮塔作为一个功能附件承受整体伤害，编辑用方块不是载具主体中的独立可脱落块。射界由作者配置，编辑器不会自动推断舰桥等结构对应的禁射区。
