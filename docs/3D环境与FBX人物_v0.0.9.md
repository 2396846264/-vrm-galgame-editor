# 0.0.9：3D 环境与 FBX 人物

这次可以在一个独立窗口里搭建 3D 场景，再让故事中的幕使用它。以前的背景图片也能继续使用：它会变成放在远处的一块薄板。

## 1. 打开环境编辑器

点击编辑器顶部的“环境编辑器”。左边是 16:9 场景画面，下方管理素材，右边查看场景里的物体。

![独立环境编辑窗口](images/v009/environment-editor.png)

点击“＋新建”创建环境。“打开一个环境”会列出当前工程创建过的环境，不需要去电脑里找另一个文件。环境和素材一起放在 `.vrmg` 工程压缩包里。

## 2. 把素材摆进场景

- 导入贴图已经装在里面的 `.glb`，双击素材或拖到场景中。
- 导入图片后，它是一块可以移动、旋转、缩放的薄板，可以放在远处做远景。
- 用移动、旋转、缩放按钮调整物体。右边的位置数字按米填写。
- Shift 或 Ctrl 可以多选，再创建分组；分组可以折叠、拆开。
- 可以添加地面、点光源和天空球，设置天空颜色与主灯亮度。
- “吸附”和“落到地面”帮助摆放。透明的左、中、右参考人物帮助找到合适镜头。
- 调好画面后点击“当前镜头作为游戏镜头”，再保存；标题和各幕可以引用同一个环境。

常用快捷键：G 移动，R 旋转，S 缩放；接着按 X / Y / Z 限定方向。Enter 确认，Esc 取消；Ctrl+Z 撤销，Ctrl+Shift+Z 重做。中键旋转视角，Shift+中键平移，滚轮拉近或拉远。

## 3. Mixamo 骨骼的 FBX 人物

素材库增加“FBX 人物”。把带有 Mixamo 骨骼的 `.fbx` 人物导入，再给角色选这个模型。可播放身体动作，也可在标题和人物鉴赏中使用。

![FBX 人物标题画面](images/v009/title-fbx.png)

![FBX 人物鉴赏](images/v009/fbx-gallery.png)

FBX 人物只播放身体动作，表情、口型选项会隐藏。待机和站立交谈动作支持固定脚掌；走路、跑步保持自由迈步，必要时可在高级动作选项里手动选择。

## 4. VRM 对话和真实阴影

VRM 人物继续支持动作、表情和对白头像。在 3D 场景中，人物阴影投到地面和墙壁上，并受场景灯光影响。

![3D 教室中的 VRM 对话](images/v009/classroom-vrm.png)

VRM 素材卡片优先显示模型自带的头像。程序自动生成的对白头像放进隐藏分类，普通图片素材栏更加整齐，对白里的头像照常使用。

## 5. 前后位置可以输入数字

人物移动太多时，直接在“前后位置”右侧输入数字，例如 `0.01` 或 `-2.41`。小箭头每次调 `0.01`，滑动条与数字同步。标题人物、每幕站位、对白人物都可以这样调。

![前后位置精确输入框](images/v009/depth-number.png)

## 当前范围

环境物体目前使用贴图内嵌的 GLB。FBX 这次用于 Mixamo 骨骼人物；通用 FBX / OBJ 场景导入与自动转换还没有加入。独立材质编辑、Prefab、实例化、LOD、KTX2 / Meshopt 优化仍是后续工作。当前可以多次摆放同一个 GLB，并使用它原有的材质贴图。

截图展示作者本地素材的效果。公开程序包不包含截图中的学校、建筑、汽车或人物模型，也不附带第三方动作文件。使用者请准备自己的素材。

## 检查结果

网页和 Windows 程序编译通过；检查了环境保存、层级分组、相机站位、真实阴影、Mixamo 动作、VRM 内置头像。前后位置检查覆盖数字输入、滑动条同步、空输入以及保存后保留数值。
