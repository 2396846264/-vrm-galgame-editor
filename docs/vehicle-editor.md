# 载具编辑器 0.0.48

程序安装目录：`本地交付目录`。源码已更新到原来的“换电脑继续开发_0.0.44”源码目录。

本版继续采用独立载具文件、第一人称建造、半边机体自动对称的方式，新增更小的构件、异形块、活动起落架、正面投影风阻及武器反馈。当前载具类型是飞机；战舰、坦克、航空母舰甲板和弹射器尚未加入。

## 打开一份载具

主界面进入“载具编辑器”，或在空战幕里点“打开载具文件”。右上角的“打开一个载具”选择工程内文件；编辑器只显示当前这一架。切换文件前保存当前修改。“＋ 新建”提供空白飞机、Ju87G-2、B-25H、Bf109G-6、震电四款模板。

“保存”或 Ctrl+S 将文件保存到工程包。主界面的空战幕分别选择玩家、友军、敌军使用的载具文件；保存载具后，引用它的空战幕会同步更新。这套打开方式沿用环境编辑器，文件随工程包携带，目前没有独立 `.vehicle` 文件导入导出入口。

## 12.5厘米构件与异形块

默认网格边长为 **0.125米**，是最初0.5米构件边长的四分之一。主体保存为独立构件，绘制时合并相邻正方体、隐藏内部面。整机仍限制在10,000个三角面以内。

材料和形状分开选择：轻型机身、升力机翼、尾翼稳定面、装甲、不透明驾驶舱，都可选择正方体、三角斜面体、四角尖锥、圆锥。斜面可用在机鼻、翼尖、边缘与过渡位置，避免整架飞机只能堆成矩形。不同实体形状按各自体积计算质量与结构耐久。

机头固定朝 **−Z**，机尾朝+Z，向上为+Y。机体只在 **X≥0右半边**建造，左半边自动生成，中心线构件只保留一份。异形块的方向也会正确镜像；中心线上的形状必须保持左右对称。

发动机与螺旋桨、襟翼、炮塔、机枪、机炮、起落架、炸弹等是预制附件，可自由安装在吸附网格上。附件默认独立；勾选“附件自动对称复制”才会在对面创建同款附件。副本创建后可独立调整与拆除。

点“进入第一人称建造”后：

| 操作 | 按键 |
|---|---|
| 移动、转头 | WASD、鼠标 |
| 上升 / 下降 / 加速 | Space / Ctrl / Shift |
| 放置 / 拆除 / 选择 | 左键 / 右键 / 中键 |
| 偏航 / 俯仰 / 滚转90° | R / T / Y |
| 释放鼠标，再操作右侧属性 | Esc |
| 保存 / 打开 / 新建 | Ctrl+S / Ctrl+O / Ctrl+N |

右侧可修改构件形状、方向和颜色，附件可修改位置、安装角度、倍率及发动机马力。已有较粗机体在打开时细化、重新吸附，保存后才应用到工程。

## 起落架

起落架有可活动的支柱、轮轴、轮辐与轮子。轮子按地面滚动速度和实际轮径转动，倒退时反转；离地后转速逐渐下降。

选中起落架，在右侧选择**向前、向后、向内、向外**折叠，并用“预览起落架收放 / 轮子滚动”观察。左右支柱在向内、向外折叠时使用相反的转轴方向。

默认在离地20米以上且速度足够时自动收轮，收放过程有过渡动画。飞行时G可手动收放，右上角HUD显示收放状态。编辑器有“地面起飞”入口；空战幕也可勾选“从地面滑跑起飞”。地面滑跑后达到速度再拉起，离地后会自动收轮。

这一版准备了平地上的轮胎接触、滑跑、离地与收轮行为。航母甲板碰撞、舰体运动、弹射器和拦阻索属于后续功能。

## 风阻与武器

风阻基于模型沿机头方向的**整机正面投影**计算，重叠机体和附件只计一次。可见轮廓按材料与附件的阻力系数合成，使用动压计算寄生阻力；机翼另算诱导阻力。起落架收起时，迎风面积与阻力会相应变化。右侧显示正面投影面积、等效阻力面积、质量、马力、升力面积及估算失速速度。

武器更新包括：

- 每门武器独立计算射速、初速和弹药量，75mm炮为低射速。
- 弹丸从实际炮口发射，机枪与炮弹有重力下坠、空气减速和曳光表现。
- 炮管后坐、炮口焰及玩家射击音效。
- 自卫炮塔底座偏航、炮管俯仰，按转速追踪射界内敌机，瞄准后开火。双联炮塔使用各自炮口。
- 命中时出现火花、命中提示和部件闪光；击毁时显示击毁提示。异形块使用形状碰撞，避免空的斜角也算命中。

飞行操作：鼠标指向控制航向，W/S调油门，A/D辅助滚转，Q/E方向舵，方向键俯仰，左键或空格射击，B投弹，F襟翼，G起落架，Esc暂停。空战存档仍是任务检查点，读档会重开当前任务。
