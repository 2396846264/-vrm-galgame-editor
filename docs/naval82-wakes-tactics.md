# 0.0.82 航迹、出生距离与舰队机动

鱼雷入水并开始航行后会留下细长青白色水面尾迹；空中的鱼雷不产生尾迹。航行舰船会在舰艉产生向两侧扩散的尾流。停止、沉没或失去动力后停止生成新尾迹，已有尾迹逐渐消散。特效共用数量受限的实例网格，暂停时冻结，退出战斗时释放。

双方舰队默认出生锚点为 X=0、Z=+17500 / -17500 米，相距 35 km。原版未改动的默认舰队出生坐标自动转为新默认值；自定义坐标继续保留。双方飞机默认纵向出生距离为 20 km，队内编队间隔不变。

双方舰队距离小于 20 km 时，AI 寻找敌方舰艏前方的交叉点，向其侧前方机动，争取本舰横向火力对敌舰舰艏的 T 字优势。接近交叉点后保持侧舷对敌；双方都会尝试抢位，不能保证一方必然取得优势。决策保留转向侧并间隔重算，转弯速度仍受舰船限制，全队保持原阵型。双方拉开到 22 km 后恢复巡航。静止舰队保持静止，失去动力的舰船继续退出机动编队。

炮塔独立跟踪与装填，可在前进和转弯中开火；弹道计入发射舰和目标的相对速度。舰炮射程、射界、炮塔转速和装填时间继续生效，远距离出生不代表小口径火炮可以立即开火。

飞机和战舰编辑器的全部方块及功能附件目录显示血量。切换建造形状时，方块血量按实际体积和最低血量规则更新；已放置方块和附件在属性中显示对应血量，计算与战斗共用函数。

验证入口：`scripts/test-naval82.mjs`、既有海战/水中弹/空战回归，以及原生 `--smoke-naval80`。原生检查包含双方舰船航行转向中开火、T 字机动、舰船和鱼雷尾迹、两个独立载具编辑器的血量标注与不同窗口尺寸、工程保存重开及导出游戏。
