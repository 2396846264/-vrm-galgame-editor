# 0.0.85 海空战渲染预设

海空战幕设置新增“海空战画面渲染”，复用普通对白相同的预设选择、亮度、对比度、饱和度微调控件。详细效果仍在独立渲染编辑器制作，不再新增一套滤镜参数。

选中的预设保存在该幕的 `event.render`，共享工程内的渲染预设。预设修改后可更新海空战预览，保存、重开和导出游戏保留选择；删除预设时清理海空战引用，回到原始画面。普通对白与海空战的选择和微调各自保存，不互相覆盖。

海空战三维画面复用现有 `StylizedPipeline`，支持已有轮廓、边缘光、景深、雾气、泛光、颜色及胶片类滤镜；色块和反光参数作用于兼容的载具材质。飞机与战舰标为此画面中的主体，因此“仅照亮角色”也可作用于载具。亮度等微调仅作用于三维画布，HUD、准星和按钮保持清晰。空战对话的人物头像同步此幕渲染选择。

未使用详细滤镜时继续直接渲染，不分配后处理目标；回到原始画面时释放目标。开启后处理会增加显存及 GPU 开销，复杂场景可减少泛光、景深、轮廓宽度等效果。窗口改变尺寸时同步调整颜色与深度目标，结束或重新开始战斗时释放相关资源。

本次另提供 [GitHub 水面技术调研](ocean-research-2026-10-21.md)，仅调研候选项目，没有替换现有水面或新增外部依赖。

验证入口：`scripts/test-air-render85.mjs`、既有渲染预设和海战回归；原生检查覆盖海空战预设与微调控件、实际 GPU 像素变化、色块着色器、尺寸调整、原始画面回退、保存重开与导出游戏。
