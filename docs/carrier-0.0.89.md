# 0.0.89 编队、玩家机与补给后复飞

每个友方编队最多六架，包含玩家机。添加或替换飞机时，在小窗口中勾选“设为玩家飞机”；全场只保留一架玩家机，槽位会标注“玩家”。主页面的玩家机选择与这个槽位同步，运行时不会再额外生成一架玩家机。

旧版七格编队自动迁移，多出来的飞机移入其他空位或编队，保留原机型。友军 AI 总数仍不超过十五架，另有唯一玩家机。空中出生时采用所属编队的高度和位置；每个编队可勾选“在航空母舰上出生”，选择已添加的具体友方航母；没有友方航母时该选项置灰。未勾选时高度为出生高度，勾选时高度用于 AI 离舰后的巡航爬升。旧工程自动分配行为保留。

每艘航母最多停放六架，还会检查机体宽度、长度和甲板可用距离。自动分配时优先让同一编队使用同一艘航母，放不下时尝试其他航母；指定航母时只使用所选舰只。仍无位置则保留为空中出生。队友先起飞，玩家最后按 W 起飞。界面显示友军航母数量与人数提示。

返航停稳、低油门补给五秒后，补给只执行一次。飞机随后进入甲板起飞队列，自动牵引到舰艉起飞位并对正舰艏。停稳后的接触会跟随海浪升沉与甲板倾斜，避免补给计时被接触抖动打断。此过程会跟随航母移动，不需要玩家在甲板边缘手动调头。等待完成后提示按 W 起飞；滑跑达到安全速度后才允许离舰，不再把“滑出了甲板”当作成功起飞。

满甲板时，新降落的飞机会自动复飞并提示等待。甲板损毁或航母沉没会中止队列并执行原有空中恢复流程。尺寸不适配、发动机完全损毁等情况会给出提示，避免直接开始不安全滑跑。

本次先复现了旧问题：170 米甲板上停在舰艏附近的飞机，补给后直接加油，离舰速度只有约 3.5 m/s，测试中掉海。修改后验证了 170、240、350 米甲板、两个航向、四种停放位置共二十四种组合；检查了牵引、对正、起飞速度，并继续执行离舰后的飞行物理。另检查六机编队、双航母、溢出、玩家唯一性、勾选迁移和保存重开。
