# 项目背景速览

这份短说明从已有开发记录和当前源码整理，便于接手者快速了解公开版。

## 项目目标

制作能在 Windows 上直接运行的 VRM Galgame 编辑器：作者用 3D VRM 角色、分幕剧情、对白、动作、图片和声音制作视觉小说，并导出可游玩的游戏。

## 当前公开版

`0.0.1` 是首次公开版本号，功能以本地 `v0.7.4` 为基础。编辑器使用 Web 前端与 Windows 桌面外壳；工程保存为单个 `.vrmg` 包。公开源码与便携包不包含第三方 VRM、FBX 动作或示例故事素材。

## 最近完成的功能

- `v0.7.2`：最近工程、玩家自动存档、鉴赏解锁记录。
- `v0.7.3`：游玩进度、人物鉴赏布局、图像是否加入鉴赏的选择。
- `v0.7.4`：本幕人物、单句对白与标题人物的前后距离；统一的角色脚下阴影，默认关闭。

## 使用顺序

新建或打开工程 → 导入自己的素材 → 设置角色与幕 → 编写对白 → 试玩 → 保存 `.vrmg` → 导出游戏。

## 已知边界

- 脚下阴影投在虚拟地面上，因为背景可以是一张二维图片。
- 公开包未内置人物和动作；空白工程可正常创建，需要作者导入自己的素材。
- 需要 Windows 10/11 x64 与 WebView2 Runtime。
