# v0.7.27：自动说话嘴型

## 现在说话时会动嘴

对白逐字显示时，说话的角色会自动在 A、I、U、E、O 嘴型之间平滑切换，张嘴幅度有大小变化，并穿插短暂闭嘴。逗号、句号、省略号等标点处，会短暂停顿。

文字显示完成时，嘴型运动立即结束，恢复作者原先设定的嘴型。玩家点击画面或按空格，让整句立即显示时，也会立即停止动嘴。

只让当前说话、且站在场上的 VRM 角色动嘴。其他角色、纯文字旁白和静态头像保持原样。没有配音的对白也可以使用。

## 开关位置

编辑器左侧“角色” → 选择角色 → 右侧“角色设置” → **自动说话嘴型**。

- 开启：默认设置，旧工程的角色也自动开启。
- 关闭：这个角色不会自动动嘴，原来的嘴型滑块和动作照常使用。

开关会保存在工程包里，并随导出的游戏一起生效。修改开关支持撤销和重做。

## 和其他功能一起使用

- 只临时控制嘴型，不修改作者保存的表情滑块，不改写对白和配音素材。
- 微笑、生气、眼睛等其他表情继续保留；角色动作照常播放。
- 修改游戏的“文字出现速度”后，嘴型会跟随新的文字显示时间。
- 换说话角色、切换幕、进入世界事件或返回标题时，上一句的嘴型运动会停止。
- 编辑器选中对白时显示的是作者保存的表情；点击“试玩”进入游戏后才会自动动嘴。

这是跟随文字的说话效果，不是按配音发音准确对嘴。文字显示完成后，即使配音还没结束，自动嘴型也会停止。

模型至少需要有一个可用的 A、I、U、E、O 嘴型；缺少部分嘴型时使用已有的嘴型，没有这些嘴型时自动跳过。模型自身的表情设置也可能影响嘴型的实际幅度。

## 启动新版

打开“新版_v0.7.27_自动说话嘴型”文件夹，双击 `VRMGalgame.exe`，打开原来的工程即可。压缩包请完整解压，程序、`web`、`WebView2Loader.dll` 和 `preset-motions` 放在一起。
