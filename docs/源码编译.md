# 自己编译编辑器

如果只是制作游戏，请下载 Releases 的完整 ZIP，无需编译。

源码需要 Windows、Node.js 22 和 .NET 10 SDK。在仓库根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-windows.ps1
```

脚本会安装前端依赖、编译编辑器与 Agent、检查界面文件，并生成 `release/VRMGalgame-0.0.8-developer-win-x64.zip`。公开源码和开发包不附带第三方角色、动作或完整故事素材。

## 官方版和自己编译的版本

官方工程密码和官方签名私钥不放在公开源码里。首次编译会在 `%LOCALAPPDATA%\VRMGalgame\DeveloperIdentity` 生成自己的随机工程密码和签名密钥，后续编译继续使用它们。请妥善保留该文件夹，不要提交到仓库。

- Releases 的官方版能继续打开官方版保存的加密工程。
- 自己编译的开发版能打开旧的无密码工程，以及同一开发身份保存的工程；不能打开官方加密工程。
- 不同开发身份之间的加密工程也不能互相打开。
- 开发版导出的玩家游戏自带运行文件和界面签名，可以正常运行。

这是发布包的文件完整性检查，不是商业软件授权系统，也不能保证阻止所有修改。GitHub Actions 只验证开发版构建，不使用官方密钥或自动发布官方包。
