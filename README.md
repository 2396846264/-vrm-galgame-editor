# VRM Galgame 编辑器

用 VRM / FBX 人物和三维场景制作视觉小说。

0.0.32 修复人物鉴赏切换卡顿，并包含完整切幕加载、30 人队列、音乐音效分离、角色动作文件夹及右键复制删除。

[下载 Windows 安装包](https://github.com/2396846264/-vrm-galgame-editor/releases/latest)。公共安装包不附带角色模型、工程及第三方动作素材，可以自行导入；工程中已有的素材照常使用。

源码构建：安装 Node.js 与 .NET 10，运行 `scripts/build-windows.ps1`。开发构建使用自己的加密身份；私钥不包含在源码中，开发版不能读取官方加密工程。
