# VRM Galgame 编辑器

使用 VRM / FBX / MMD 人物和三维场景制作视觉小说。

最新版 0.0.39：MMD 模型与物理支持、动态头像修复、角色详情、游戏 UI 风格和存档截图。

[下载 Windows 安装包](https://github.com/2396846264/-vrm-galgame-editor/releases/latest)。公开包不附带角色模型、工程及第三方动作素材，可以自行导入；工程中已有素材照常使用。

源码构建：安装 Node.js 与 .NET 10，运行 `scripts/build-windows.ps1`。开发构建使用自己的加密身份，私钥不包含在源码中，开发版不能读取官方加密工程。
