# VRM Galgame 编辑器

使用 VRM / FBX / MMD 人物和三维场景制作视觉小说。

最新版 **0.0.50**：载具编辑器与空战幕、自动眨眼和自然视线。多人场景中的自动眼神和眨眼会错峰触发。

[下载 Windows 版](https://github.com/2396846264/-vrm-galgame-editor/releases/latest)。公开包不附带第三方模型、动作素材和用户工程，可以自行导入。

[載具编辑器](docs/vehicle-editor.md) · [自动眨眼](docs/auto-blink.md) · [自然视线](docs/natural-gaze.md)

源码构建：安装 Node.js 22 或更新版本和 .NET 10，运行 scripts/build-windows.ps1。公开源码构建用于独立开发测试，使用独立的开发身份；日常使用请下载正式发布版，以保留现有加密工程兼容性。
