# VRM Galgame 编辑器

使用 VRM / FBX / MMD 人物和三维场景制作视觉小说。

最新版 0.0.44：扩展 MCP 编辑、景深与镜头互动、渲染预设制作和角色详情画面选择。

[下载 Windows 安装包](https://github.com/2396846264/-vrm-galgame-editor/releases/latest)。公开包不附带第三方模型、动作素材和用户工程，可以自行导入。

源码构建：安装 Node.js 22 或更新版本和 .NET 10，运行 `scripts/build-windows.ps1`。公开源码构建用于独立开发测试，日常使用请下载正式发布版。
