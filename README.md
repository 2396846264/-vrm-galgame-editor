# VRM Galgame 编辑器

用 VRM / FBX 人物和三维场景制作视觉小说，支持剧情、物品分支、角色绑定物品、逐句镜头及独立编辑窗口。

0.0.25 新增玩家抗锯齿、超采样、FSR 1.0、绘制分辨率和阴影设置，保留资源保护与近期修复。

[下载 Windows 程序包](https://github.com/2396846264/-vrm-galgame-editor/releases/latest)，解压后运行“启动编辑器.bat”。

源码构建：安装 Node.js 与 .NET 10，运行 `scripts/build-windows.ps1`。构建脚本生成自己的开发加密身份；私钥不包含在源码中，开发版不能读取官方加密工程。
