## 开始使用

1. 下载 Windows x64 便携版，解压后运行 `VRMGalgame.exe`。需要 Microsoft Edge WebView2 Runtime。
2. 新建或打开 `.vrmg` 工程，自行导入有权使用的角色、动作、图片与声音。
3. 在“编辑器”中打开角色、场景、游戏 UI、飞机、战舰等独立编辑器。
4. 导出 Windows 游戏后，可离线运行，也可将自己制作的游戏用于商业发行。

## 开发

使用 Node.js 22+ 与 .NET 10。执行 `scripts/build-windows.ps1` 构建开发版；保留构建脚本生成的本机身份目录。开发版工程与正式版工程请分别备份并使用相应版本打开。第三方依赖及字体许可见 `licenses/`。
