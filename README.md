## 上手

1. 从[Releases](https://github.com/2396846264/-vrm-galgame-editor/releases/latest)下载安装包或便携ZIP。Windows x64，需要Microsoft Edge WebView2 Runtime。
2. 运行`VRMGalgame.exe`，新建或打开`.vrmg`工程。导入自己的模型、动作、图片和声音。
3. 在主界面编排剧情，通过“编辑器”进入角色、场景、载具等独立页面，试玩后导出游戏。
4. 使用Agent时，在“剧情助手”开启本地接口并复制MCP配置；更新程序后重新复制配置。
5. 示例ZIP提供自行搭建的场景工程，打开后可在场景编辑器中选择港口或庭院。

## 当前边界

载具目前支持螺旋桨飞机，未实现坦克、战舰和移动航母；海上平台没有弹射器或阻拦索。飞行与武器为游戏近似模拟，水面为视觉组件。几何体场景保留结构和配色，尚未达到手绘背景的纹理细节。空战读档从任务检查点重开。当前提供Windows版，Android导出已取消。

## 开发构建

使用Node.js 22+与.NET 10，运行`scripts/build-windows.ps1`。公开源码不含正式构建的私有凭据；开发构建使用独立身份，日常使用正式加密工程请下载正式版，保留自己的工程与开发身份备份。第三方依赖说明见`licenses/`。
